# セッションを締める

このセッションで分かったことを、次のセッションに確実に引き継ぐ。

現在の状態:

- ブランチ: !`git -C "${CLAUDE_PROJECT_DIR}" branch --show-current`
- 開いている PR: !`cd "${CLAUDE_PROJECT_DIR}" && gh pr list --state open --json number,title -q '.[]|"#\(.number) \(.title)"' 2>/dev/null | head -10`
- 未コミットの変更: !`git -C "${CLAUDE_PROJECT_DIR}" status --short | grep -v '^??' | head -20`

## 1. 起票漏れを点検する

このセッションの会話を振り返り、次のものを列挙する。

- 見つけたが直していない不具合・改善点
- 「あとでやる」「今回は範囲外」と判断したこと
- ユーザーが気にしていたが結論が出ていないこと

それぞれ、Issue・非公開の記録・後回しの台帳のどこかに**残っているか**を確かめ、残っていないものを起票または追記する。セキュリティに関わるものは公開しない。

## 2. ハーネスを振り返る

このセッションで、ハーネス（CLAUDE.md・CLAUDE.local.md・スキル・テンプレート）に関わる摩擦がなかったかを振り返る。

- 同じ訂正・同じ説明を2回以上した
- スキルの手順が実際の作業に合わなかった（飛ばした・毎回補った）
- 指示が曖昧で迷った、指示どうしが食い違っていた
- 書かれていることが実態と違った

見つけたら、小さなものは差分つきでその場で提案する。すぐに決めないものは、改善案の置き場（場所は `CLAUDE.local.md`）に追記する。

## 3. 計画を最新にする

非公開の計画（場所は `CLAUDE.local.md`）を更新する。

- 今後の順番と、それぞれの状態（完了・進行中・未着手）
- 後回しの台帳: 片付いたものに印を付け、新しく後回しにしたものを足す

## 4. メモリを更新する

次のセッションで役立つことだけを、メモリに残す。

- ユーザーの新しい指示・好み・訂正
- 進行中の作業の状態（どこまで終わり、何が残っているか）
- コードや git の履歴から読み取れることは書かない

## 5. 保存してまとめる

- 非公開の記録と計画に変更があれば、非公開のリポジトリに commit と push をする
- ユーザーに次の3点を短く伝える
  - このセッションで終わったこと
  - 起票・追記したもの
  - 次にやること（最初の一手）
